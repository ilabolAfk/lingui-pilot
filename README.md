# LinguaPilot

**Обучайтесь языкам с локальным ИИ — без облаков и подписок.**

Английский, немецкий, французский и испанский. Все данные и нейросеть работают **локально** на вашем компьютере через [Ollama](https://ollama.com/).

</div>

---

## ✨ Возможности

| Модуль | Что умеет |
|---|---|
| 💬 **Диалог** | Учитель-ИИ поддерживает разговор, исправляет ошибки и развивает беседу |
| 🃏 **Карточки** | Флешкарты с интервальным повторением (алгоритм SM-2) |
| 📖 **Истории** | Генерация историй на изучаемом языке: жанр, длина, словарик и вопросы с проверкой |
| 🏋️ **Практика** | Упражнения на грамматику с вариантами ответа и объяснениями |
| 🎤 **Произношение** | Распознавание речи через браузерный Web Speech API |
| 📝 **Экзамен** | Уровни CEFR **A1–C2**, таймер, результат с достигнутым уровнем |
| 📄 **Свой текст/PDF** | Разбор вашего текста или PDF на задания; экспериментальный **OCR** для сканов |

## 🧠 Выбор нейросети

Используются модели Qwen (можете установить любую через Ollama):

- `qwen2.5:7b-instruct` — быстрая (~4.7 ГБ)
- `qwen3:14b` — сбалансированная (~9.3 ГБ)
- `qwen2.5:7b` — лёгкая (~4.7 ГБ)

Активная модель выбирается в шапке приложения и запоминается.

## 🚀 Запуск (для разработки)

Требуется **Python 3.10+** и **Ollama** ([скачать](https://ollama.com/)) с установленной моделью.

```bash
pip install fastapi uvicorn ollama pypdf python-multipart pillow pytesseract reportlab
ollama pull qwen2.5:7b
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000**

## 📦 Готовая сборка (Windows)

Собранный установщик лежит в **релизах** — один `.exe`, который сам:

1. ставит Ollama (если её нет);
2. ставит приложение и ярлыки с иконкой;
3. запускает лаунчер, где выбирается и скачивается модель.

### Сборка из исходников

```bash
python build.py                       # собрать server + launcher exe (PyInstaller)
ISCC installer.iss                    # собрать установщик (Inno Setup)
powershell -File sign.ps1 -SkipBuild  # подписать self-signed сертификатом (опционально)
```

## 🛠️ Технологии

- **Backend:** Python + FastAPI + SQLite + Ollama
- **Frontend:** чистые HTML/CSS/JS, Font Awesome 6
- **Сборка:** PyInstaller + Inno Setup
- **OCR:** Tesseract (опционально, режим «бета»)
